# Stackly — Reports & Analytics Dashboard Platform

A modern, responsive, glassmorphic Reports & Analytics dashboard web application featuring rich interactive charts, KPI metrics, scroll-reveal entrance animations, fixed parallax city background, dedicated authentication gateway, and mobile/desktop responsive design.

## ✨ Key Features

- **🔐 Dedicated Authentication Gateway**: Secure login page with credentials verification (`admin@stackly.com` / `admin123`), password visibility toggle, and instant transition to the dashboard.
- **🌆 Parallax Skyscraper Background**: Premium fixed background with glassmorphic cards and subtle gradient overlays.
- **📊 13 Core Analytics Topics & Widgets**:
  1. **KPI Metric Cards**: Revenue ($128,430), Active Users (42.8k), Conversion Rate (3.42%), Avg. Session (4m 32s) with sparklines and growth badges.
  2. **Interactive Charting Suite**: Spline, Bar, Area, Line, and Donut charts with real-time time-frame filters (7D, 30D, 90D, 1Y).
  3. **Segmented Donut Breakdown**: Traffic acquisition channels with dynamic percentage updates.
  4. **Deliverables & Transactions Data Table**: Interactive status filtering, live search query, pagination, and multi-select actions.
  5. **System Pipeline & Health Monitor**: Real-time server load, query latency, and uptime gauge indicators.
  6. **Data Export Suite**: Instant export to CSV, JSON, and printable PDF report generation.
- **👤 Super Admin Profile Dropdown**: User avatar menu with status indicator, profile info, settings, and one-click logout.
- **📱 Universal Responsive Layout**: Fully responsive across mobile screens (down to 320px), tablets, and widescreen desktop displays, including a mobile hamburger menu drawer.
- **✨ Scroll-Reveal Animations**: Smooth left/right entrance animations as you scroll down the page.

## 🚀 Getting Started

### Option 1: Direct Browser Preview
You can open `index.html` or `login.html` directly in any modern web browser:
- `index.html` — Full application with Login Gateway and complete Analytics Dashboard.
- `login.html` — Dedicated standalone login interface.

### Option 2: Vite Dev Server (React)
```bash
npm install
npm run dev
```

## 🛠️ Tech Stack
- **HTML5 & Vanilla JavaScript**: Pure performant DOM manipulation, SVG sparklines, and Canvas/SVG charting.
- **CSS3 / Glassmorphism**: Custom CSS variables, backdrop blur filters, responsive flex/grid layouts, and keyframe animations.
- **React 18 & Vite**: Modular component architecture for scalable development.
- **Lucide Icons**: Crisp modern iconography.
